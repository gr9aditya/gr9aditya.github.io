Isaac recorded-playback export (experimental alpha)

Serve this directory over static HTTP, e.g. python -m http.server 8000.
Open that URL in a browser. Start, Pause, Restart, orbit drag, right-drag
pan, and scroll zoom are available. Browser playback does not run Isaac
physics or project controllers. Read compatibility-report.json for
capture and conversion findings. Review source-asset permissions
before distributing a package containing third-party content.
